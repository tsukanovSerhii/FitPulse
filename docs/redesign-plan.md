# FitPulse — план редизайну

Референс: мінімалістичний темний «editorial» лендінг (Aer — Work Anywhere): графітовий фон, велика двоярусна типографіка, тонкі розділювачі, нумеровані секції `/ 01`, один теплий акцент, вертикальна панель зліва, нижня інформаційна смуга з картками.
Ціль: та сама естетика, але під спорт/тренування, з повноцінним перемиканням **світла / темна / системна** тема.

### 1.3 Чому тема зараз «ламається»
- **35 файлів** з прямими кольорами Tailwind (`text-slate-400` ×58, `text-sky-400` ×40, `text-white` ×33, `emerald-*`, `amber-*`…) — вони не реагують на тему.

### 1.4 Що добре і лишається
Архітектура feature-sliced (`features/*/model|api|components`), Redux Toolkit, утиліта `cn` (clsx + tailwind-merge), lucide-іконки, тести бізнес-логіки. Редизайн — це **шар представлення**: слайси, API та утиліти не чіпаємо.

## 2. Дизайн-напрям: «Athletic Editorial»

### 2.1 Принципи
1. **Типографіка — головний візуальний елемент.** Великі стиснені заголовки великими літерами, цифри — моноширинні.
2. **Один акцент.** Усе інше — відтінки графіту/паперу. Акцент лише для активного стану, CTA та ключових цифр.
3. **Лінії замість тіней.** Тонкі розділювачі 1px, мінімум заокруглень (4–8px), без градієнтних «світінь».
4. **Нумерація секцій** `/ 01`, `/ 02` — як у референсі, задає ритм і «спортивний протокол».
5. **Фото/силует атлета** як фоновий герой на Dashboard (можна взяти кадри, що вже використовує ExerciseMotionPlayer).

### 2.2 Кольорові токени

Три шари: primitive → semantic → component. Компоненти бачать **тільки семантичні** токени.

| Семантичний токен | Dark | Light | Призначення |
|---|---|---|---|
| `--bg` | `#0E0E10` | `#F4F4F2` | фон сторінки |
| `--surface` | `#161618` | `#FFFFFF` | картки, панелі |
| `--surface-2` | `#1F1F22` | `#ECECE9` | вкладені блоки, інпути |
| `--line` | `rgb(255 255 255 / .08)` | `rgb(0 0 0 / .08)` | розділювачі |
| `--line-strong` | `rgb(255 255 255 / .16)` | `rgb(0 0 0 / .16)` | рамки інпутів, hover |
| `--fg` | `#F4F4F5` | `#111113` | основний текст |
| `--fg-muted` | `#A1A1AA` | `#55555C` | вторинний текст |
| `--fg-subtle` | `#8E8E98` | `#67676F` | підписи, плейсхолдери |
| `--accent` | `#E2B259` | `#865A0B` | акцент (теплий «медальний» золотий, як у референсі) |
| `--on-accent` | `#0E0E10` | `#FFFFFF` | текст на акценті |
| `--success` / `--danger` / `--warning` | приглушені версії зеленого/червоного/бурштинового | | статуси підходів, PR, помилки |

Альтернатива акценту — «volt» `#C6F432` (більш спортивний, неоновий). Рішення — див. розділ 6.
Усі пари текст/фон перевіряються на контраст ≥ 4.5:1 (у світлій темі акцент навмисно темніший).

### 2.3 Типографіка

Скіл радить Barlow / Barlow Condensed, але **Barlow не має кирилиці**, а інтерфейс український. Тому:

| Роль | Шрифт | Використання |
|---|---|---|
| Display | **Oswald** 500–700, UPPERCASE, tracking −0.01em | Заголовки сторінок, герой «ТРЕНУЙСЯ / БУДЬ-ДЕ» |
| Body / UI | **Manrope** 400–700 | Текст, кнопки, навігація |
| Numbers | **JetBrains Mono** 500–700, `tabular-nums` | Таймери, вага, повтори, статистика |

Шкала: 12 / 14 / 16 (база) / 20 / 28 / 40 / 64 / 88px (герой). Line-height 1.5 для тексту, 0.95 для display.

### 2.4 Простір і рух
- Сітка 4px; секції з відступами 48–96px; контейнер `max-w-7xl`.
- Переходи 150–250ms, `ease-out`; зміна теми — плавно, тільки `background-color`/`color`.
- Повна підтримка `prefers-reduced-motion` (вимикаємо пульсації, ping, transform-анімації).

## 3. Архітектура теми

1. **Tailwind v4 нативно:** токени в `@theme inline { --color-bg: var(--bg); … }` → з'являються звичайні класи `bg-bg`, `bg-surface`, `text-fg-muted`, `border-line`, `text-accent`. Самописні `.bg-t-*` та `!important`-костилі видаляються.
2. `@custom-variant dark (&:where(.dark, .dark *));` — для рідкісних місць, де потрібен `dark:`.
3. Режими: `light | dark | system`. Збереження в localStorage, слухач `matchMedia('(prefers-color-scheme: dark)')` для `system`.
4. Побічні ефекти (клас на `<html>`, `color-scheme`, `meta theme-color`, localStorage) виносимо з редюсера в `useThemeEffect` / listener middleware. Редюсер лишається чистим.
5. Інлайн-скрипт у `index.html` лишається (без «блимання» при завантаженні), але враховує `system`.
6. SVG (`MuscleMap`, `AthleteRig`) переходять на `currentColor` та CSS-змінні замість hex.

## 4. Компоненти

### 4.1 Примітиви (`src/components/ui/`)
Варіанти описуємо простими об'єктами-мапами + `cn`, без сторонніх бібліотек.

| Компонент | Нотатки |
|---|---|
| `Button` | `primary` (акцент), `secondary`, `ghost`, `danger`; розміри sm/md/lg; `asChild` для лінків; мін. висота 44px на мобільних |

Доступність: власна реалізація клавіатурної навігації для Dialog, Tabs, Select (стрілки, Esc, Home/End, roving tabindex).

### 4.2 Каркас (`src/components/layout/`)
Повторює композицію референсу:

```
┌──────┬──────────────────────────────────────────────────────┐
│  ≡   │  FITPULSE        Головна  Вправи  Програми  Прогрес ◐ │  ← Topbar: активний пункт підкреслений акцентом
│      │                                                      │
│      │  / 01                     ТРЕНУЙСЯ                   │
│      │  Сьогодні: Push Day       БУДЬ-ДЕ                    │  ← Hero з фото атлета на фоні
│      │  Наступне: Pull Day       короткий опис, CTA          │
│  ◐   ├──────────────────────────────┬─────────┬─────────────┤
│  ⚙   │  НАСТУПНЕ ТРЕНУВАННЯ          │  фото   │  РЕКОРД      │  ← нижня смуга (Info strip)
│      │  …                           │         │  …          │
```

- `AppRail` — вузька вертикальна панель: меню, перемикач теми, профіль.
- `Topbar` — логотип-слово + текстова навігація + кнопка «Почати тренування».
- `MobileTabBar` — ≤5 пунктів, внизу екрана (<768px).
- `Footer` — мінімальний, один рядок.
