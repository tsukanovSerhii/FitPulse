# Адмінка: новий вигляд і детальна аналітика

Дата: 2026-11-08. Статус: на погодженні.

## Рішення власника

| Питання | Рішення |
|---|---|
| IP і країна | Країна й місто визначаються під час входу; IP зберігається урізаним (`93.75.12.x`, для IPv6 перші 48 біт) і лише 90 днів |
| Що показувати | Пристрої й браузери, час у застосунку, країни й міста, графіки за днями (реєстрації, активні, тренування, утримання) |

## Що збирається

**Під час входу, реєстрації й refresh** (сервер застосунку), у рядку сесії:
- `device_type` (`mobile` / `tablet` / `desktop`), `os`, `browser` — з User-Agent (бібліотека `ua-parser-js`);
- `app_mode` (`browser` / `installed`) — заголовок `X-App-Mode`, який застосунок надсилає з `matchMedia('(display-mode: standalone)')`;
- `country` (ISO-код), `city` — з бази DB-IP City Lite (CC BY 4.0) за IP відвідувача;
- `ip_prefix` — урізаний IP;
- `last_seen_at` — оновлюється під час refresh.

Повний IP ніде не записується (ні в базу, ні в лог запиту).

**Час у застосунку.** Поки вкладка видима й користувач увійшов, застосунок раз на 60 с надсилає `POST /api/activity` (порожнє тіло, з access-токеном). Сервер додає 1 хвилину в `user_activity(user_id, day, minutes)` (не більше 1 хвилини на 50 с для користувача — Redis-ключ із TTL). Офлайн-хвилини не рахуються.

**Зберігання.** Щодня (під час старту API й далі раз на 24 год) `ip_prefix` сесій старших за 90 днів очищується, а `user_activity` старше 400 днів видаляється. Видалення акаунта прибирає все каскадом.

Політика конфіденційності отримує розділ: що збирається, навіщо (безпека входу й статистика використання), скільки зберігається, джерело геоданих.

## API адмінки (будь-яка роль)

| Шлях | Що повертає |
|---|---|
| `GET /api/analytics/overview?days=30` (7/30/90) | за днями: реєстрації, активні користувачі (хоч одна хвилина), тренування, хвилини; середні хвилини на активного; утримання: частка зареєстрованих 8–14 днів тому, що були активні за останні 7 днів |
| `GET /api/analytics/devices?days=30` | розподіл за типом пристрою, ОС, браузером, режимом (сайт / встановлено) — за останнім входом кожного користувача в періоді |
| `GET /api/analytics/geo?days=30` | топ-20 країн і топ-20 міст за кількістю користувачів |
| `GET /api/users/:id` | додає: хвилин за 7 і 30 днів, список останніх 10 сесій (пристрій, ОС, браузер, режим, країна, місто, урізаний IP, створено, остання активність, активна/завершена) |

## Новий вигляд адмінки

- Бокова панель з розділами (на телефоні — верхнє меню), іконки, світла й темна тема за системою.
- **Огляд**: плитки з числом і зміною до попереднього періоду, перемикач 7/30/90 днів, графіки: реєстрації й активні (лінії), тренування (стовпці), хвилини на активного; донат-діаграми пристроїв і ОС; таблиця країн і міст; підпис «IP Geolocation by DB-IP».
- **Користувачі**: таблиця з колонками (ім'я, email, тариф, статус, країна останнього входу, дата), значки статусу.
- **Картка користувача**: шапка з аватаром-ініціалами й значками, плитки активності, міні-графік хвилин за 30 днів, таблиця сесій.
- Графіки — власні SVG-компоненти без бібліотеки (менше вага, повний контроль доступності: підписи, таблиця даних під графіком для читалок екрана).

## Тести

- Сервер: розбір User-Agent (iPhone Safari, Android Chrome, Windows Edge, бот); урізання IPv4 й IPv6; країна з бази для відомої адреси і `null` для приватної; хвилина активності не рахується двічі за 50 с; агрегати огляду, пристроїв і гео на підготовлених даних; очищення старих IP.
- Адмінка: перемикач періоду перезапитує дані; графік має текстову таблицю; таблиця сесій показує урізаний IP.
- Застосунок: пульс надсилається лише для видимої вкладки увійденого користувача.
