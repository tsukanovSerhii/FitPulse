# Сховища браузера

Бекенду немає, тому дані розподілені між двома сховищами за принципом:

- **`localStorage`**: дані користувача, які мають жити між візитами;
- **`sessionStorage`**: стан однієї вкладки. Він переживає перезавантаження й переходи між сторінками, але зникає разом із вкладкою.

Доступ лише через `src/services/storage`: прямі виклики `window.localStorage` чи `window.sessionStorage` у компонентах не використовуються.

## localStorage (`services/storage/localStorage.ts`)

| Ключ | Дані |
|---|---|
| `fitpulse_accounts_v1` | акаунти: ім'я, email, хеш пароля, сіль, аватар |
| `fitpulse_auth_session_v1` | id користувача, якщо вхід із «Запам'ятати мене» |
| `fitpulse_exercises_v1` | власні вправи |
| `fitpulse_favorites_v1` | обрані вправи |
| `fitpulse_plans_v1`, `fitpulse_active_plan_id_v1` | програми й активна програма |
| `fitpulse_active_session_v1` | незавершене тренування |
| `fitpulse_history_v1`, `fitpulse_prs_v1` | журнал тренувань і рекорди |
| `fitpulse_profile_v1` | профіль: зріст, вага, цілі |
| `fitpulse_theme_v1` | обрана тема |
| `fitpulse_ad_interstitial_at` | час останнього показу повноекранної реклами |

## sessionStorage (`services/storage/sessionStorage.ts`)

| Ключ | Дані | Навіщо |
|---|---|---|
| `fitpulse_auth_session_tab_v1` | id користувача без «Запам'ятати мене» | вхід на чужому пристрої закінчується з вкладкою |
| `fitpulse_return_to_v1` | шлях, на який гість намагався зайти | після входу користувач повертається туди ж |
| `fitpulse_register_draft_v1` | ім'я та email з форми реєстрації | випадкове перезавантаження не стирає введене |
| `fitpulse_exercise_filters_v1` | пошук і фільтри каталогу | повернення з іншої сторінки зберігає вибірку |
| `fitpulse_exercise_favorites_only_v1` | перемикач «Лише обрані» | те саме |
| `fitpulse_plans_view_v1` | пошук і розгорнута програма | те саме |

Пароль ніколи не записується в жодне сховище, навіть у чернетку форми.

## Як додати новий ключ

1. Додайте ключ у `STORAGE_KEYS` або `SESSION_KEYS`. Суфікс `_v1` дозволяє змінити формат без конфлікту зі старими даними.
2. Для стану компонента у вкладці використовуйте хук:

```ts
const [value, setValue] = useSessionState(SESSION_KEYS.MY_KEY, initialValue)
```

3. Запишіть ключ у таблицю вище.

Помилки сховища (переповнення, приватний режим) не ламають застосунок: читання повертає значення за замовчуванням.
